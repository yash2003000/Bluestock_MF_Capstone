# Bluestock Mutual Fund Capstone Project

## Project Overview

This project analyses the Indian Mutual Fund industry using Python, SQL, Power BI, and advanced analytics techniques.

The project includes:

* ETL pipeline for data ingestion and cleaning
* SQLite database creation
* Exploratory Data Analysis (EDA)
* Mutual fund performance analytics
* Advanced risk metrics (VaR, CVaR, Sharpe Ratio)
* Investor behaviour analysis
* Fund recommender system
* Interactive Power BI dashboard

---

## Tech Stack

* Python (Pandas, NumPy, Matplotlib)
* SQL (SQLite)
* Jupyter Notebook

## Key Features

### 1. Performance Analytics

* Sharpe Ratio
* Alpha
* Beta
* Standard Deviation
* Maximum Drawdown

### 2. Advanced Risk Analytics

* Historical VaR (95%)
* Conditional VaR (CVaR)
* Rolling 90-Day Sharpe Ratio
* Portfolio Concentration (HHI)

### 3. Investor Analytics

* Cohort Analysis
* SIP Continuity Analysis
* At-Risk Investor Detection

### 4. Recommendation System

A simple recommender system suggests top mutual funds based on:

* Low Risk
* Moderate Risk
* High Risk
